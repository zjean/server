Segmented

Active is a surface step up, not an accent fill — a segment says what you are looking at, not what to act on. The accent emphasis is for the one case the design tints: search scope inside the search field.

Inputs

Filled, not outlined — but the fill is 1.10:1 against the content plane, so the resting hairline is what satisfies SC 1.4.11. Placeholders name the scope, never the control. lg (48px) is for the search page only.

Tabs

Always labelled — icon-only tabs are forbidden. Counts sit in the label so the strip stays one row. The active underline is an inset shadow, so switching never shifts the row.

Tooltips

Hover for 400ms. Out is immediate.

Skeleton

Mirrors the row geometry it replaces, capped at five rows however many the caller asks for. Never a spinner for a list.

Pagination

The gaps collapse rather than the numbers, so the cluster never changes width as you page.
